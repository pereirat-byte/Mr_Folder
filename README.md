Used for making the CIUSuite and Twim Extract Workflow faster. 

If you click the button that says "TWIMExtract Folder Reorganize", all folders within the selected TWIM Extract output directory that have a common name except for the last two characters contain _(number), will be merged into one folder with a truncated name that does not include _(number). The files themselves will remain the same, including their name. This program only alters folders that's why it is called Mr. Folder. 

If you click that button that says "CIU Folder Generator" then all of the folder names in the selected output directory (e.g. from Twim Extract) will have their names copied and created as subfolders in a new folder in your desktop called "Analyzed data". Within each one of those folders, the following sub-subfolders will be created: "Plots", "CIU50 and Features", and "Average".
